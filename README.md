# Abdul Hannan — AI Commercial Portfolio

Premium standalone portfolio for AI commercial ads.

- Responsive cinematic layout
- Intro portfolio film
- Five project cards mapped to their own commercial videos
- Full video viewer with native controls
- Replayable scroll-reveal animations
- Lightweight 3D depth / pointer motion

The MP4 media bundle is prepared separately because the connected GitHub write interface in this session exposes text-file writes, not binary uploads.
